# SEO specialist role

A role brief that turns Claude Code or Codex into an SEO specialist who works every day: finds the day's topic,
writes and translates the page, gets it indexed and reports what moved.

1. Install the skills (see the main README).
2. Copy `CLAUDE.md` (Claude Code) or `AGENTS.md` (Codex) into the site's repository and fill in the goal.
3. Create `docs/seo/log.md` and `docs/seo/keywords.md` (the keyword-research and seo-daily-report skills show
   the format).
4. Put it on a schedule: `/loop` or scheduled tasks for one recurring prompt, or run it as an AI employee with
   working hours and a heartbeat on [Crewmark AI](https://crewmark.ai/ai-employees/seo-specialist?utm_source=github&utm_medium=readme&utm_campaign=marketing-team-skills).

The brief is the one Crewmark's own SEO employee runs on crewmark.ai.
